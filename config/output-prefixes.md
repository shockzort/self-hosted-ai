# Output prefixes for history by algorithm

Use these prefixes in ComfyUI `Save Image`, `Save Video`, or `Save Audio` nodes. They keep the result browser grouped by algorithm.

| Workflow | Prefix |
| --- | --- |
| FLUX Schnell | `text-to-image/flux-schnell` |
| FLUX Krea Dev | `text-to-image/flux-krea` |
| Qwen Image | `text-to-image/qwen-image` |
| FLUX Kontext image edit | `image-edit/flux-kontext` |
| Qwen Image Edit | `image-edit/qwen-image-edit` |
| USO reference/style workflows | `style-transfer/uso-reference` |
| Wan2.2 5B text/image-to-video | `text-to-video/wan22-5b` |
| Wan2.2 14B text-to-video | `text-to-video/wan22-14b-t2v` |
| Wan2.2 14B image-to-video | `text-to-video/wan22-14b-i2v` |
| Wan2.2 Remix dynamic shorts | `text-to-video/wan22-remix-t2v-dynamic` |
| ACE-Step music/audio | `audio/ace-step-song` |
| ACE-Step music editing | `audio/ace-step-edit` |
| Character sheets / angles | `character/character-sheet` |
| Qwen multi-angle references | `character/qwen-multiangle` |
| Qwen illustration/anime | `text-to-image/qwen-illustration-lora` |
| Color illustration/anime | `text-to-image/color-illustration` |
| Flux2 Klein realistic/editorial | `text-to-image/flux2-klein` |
| Portrait relighting | `image-edit/portrait-relighting` |
| Wan2.2 character replacement | `text-to-video/wan22-character-replace` |
| Wan ATI motion control | `text-to-video/wan-ati-motion` |
| Video restyle | `style-transfer/video-restyle` |
| LivePortrait | `text-to-video/liveportrait` |
| ACE-Step 1.5 Turbo | `audio/ace-step15-turbo` |
| Audio stem separation | `audio/audio-separation` |

Results are exposed read-only in the browser at `http://<host-ip>:8090`.
